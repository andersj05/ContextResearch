# Arithmetic-code development and retained controls

October 2, 2026. Post-hoc offline mathematics and exact-bound inspection.
No model call, natural episode, independent trial or portable timing claim.

The prototype used a=max(0,floor(2k/3)-ceil(2sqrt(k))). `prototype_codec.py`
and `prototype_finite.py` preserve actual bytes copied before the planner
revision; `prototype_probe.py` and `prototype_probe.json` retain its eight
scored lengths. Its limit is 13/48. It remains an explicit rational-count
control in production and beats the default at several finite lengths.

`entropy_probe.py` and `entropy_probe.json` preserve the revised probe and
all eight values. The default count uses an exact integer entropy inequality
with ceil(sqrt(k*ceil(log2(k+1)))) slack. The scratch script imports evolving
production code; it is not a complete frozen historical environment. The
current checker regenerates both schedules from exact counts.

`comparison.json` is an explicitly recomputed inspected output-entropy
comparison. The old three-/six-block quantizers give weaker time-share limits
than the two-word scalar option. Its floats select a direction, not certify
bounds. All sixteen final finite bounds use exact integer/rational sums and
outward rounding. Small losing lengths and stronger prototype controls remain
in the record.

Historical files preserve original import/root/output assumptions. They are
source records, not supported package commands; use the certificate command
in the parent README. `metadata.json` binds seven files and original C69
result bytes at 8e09d1d. The final checker also validates the original C67/C69
source bindings. No old result or provider identity is overwritten or retried.
Generic entropy-constrained quantization, time sharing and arithmetic coding
are established; external proof/priority and natural-agent benefit stay open.
