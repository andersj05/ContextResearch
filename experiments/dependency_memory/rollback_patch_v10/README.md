separate v9 calibration produced no naturally failed patches. Earlier evidence
and source remain immutable.

analysis and scheduler retain their verified contracts. `runtime.py` admits
larger input batches, and the new `transport.py` aligns the actual client and
controller body bounds. No model calls occur on import or in unit tests.

permission, then independently replay it. Only a passing control-only gate can
freeze the separate 256-task main allocation. Allocation folders contain all
call ceilings, task seeds, source bindings and runtime/access contracts.
