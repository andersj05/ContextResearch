# Source-only dependency-scope inference: development experiment v1

October 1, 2026. New bounded study under the user's continuing authorization
to make online Luna model calls. This is a separate allocation; no historical
stopped or completed launch is reopened. Freeze implementation, public requests,
schedule, evaluator and source inputs before the first generation.

## Question and evidence class

Can Luna infer a complete JSON retention contract from an actual decision
program, including membership, absence and nonempty-container dependencies?
The public program is the two pure functions `exact` and `classify_attempt`
from `scripts/prepare_transfer_continuation.py`, upstream repository commit
`04141984d56fa0f80429d19dc45f589fef8ac5a6`. Its existing pinned source hash and
eight historical attempt observations are preserved by `workflow_replay`.
The handwritten projection and historical outcomes have already been inspected.
Only the public original program, its constants and the retention DSL go to
the learner. Do not provide the handwritten projection, records, test catalog,
counterexamples or evaluator labels. No model-generated code is executed.

One program, eight already inspected historical observations, and a finite
constructed control catalog are development evidence. Eight model calls are
replicates on that one program, not independent workflows or untouched tasks.
Nothing is registered as another natural episode to fill the twelve-task intake.
This tests source-driven extraction; arbitrary prose extraction, new program
families, native compaction, provider internals and production savings remain open.

## Methods and fixed online schedule

Make eight source-only calls: four paired replicates of two instructions,
`concise` and `closure`. Both get the same complete public program and DSL.
Concise asks for a compact exact contract. Closure additionally reminds the
learner to preserve membership/absence, malformed-container type, and nonempty
tests. These are separately charged, predeclared prompt variants. No feedback,
repair, replacement, retry or prompt tuning follows an observed answer.
Order pairs and instructions with schedule seed 2026100102; no model sampling
seed is exposed. Publish all eight identities before dispatch.

Return exactly three string arrays: `value_paths`, `presence_paths`,
`nonempty_paths`. Paths are dotted object keys; `$` in value_paths retains the
entire record. Literal values preserve the referenced subtree; presence retains
a fixed `true` placeholder only when the key was present. Nonempty retains
container nonemptiness with a fixed public marker if projection otherwise empties
it. Preserve any encountered nondictionary intermediate value rather than
silently converting its type. Missing paths remain missing. The compiler rejects
malformed or duplicate paths, reserves its nonempty marker, and never clips data.
Syntax admission is not semantic certification. All syntactically admitted
contracts are evaluated; errors stay errors and receive no oracle fallback.

Strong zero-model baselines: the existing handwritten critical-field projection;
a conservative literal-key AST baseline retaining whole referenced root fields;
raw full records; and cached public-program outcomes with exact record identity.
Caching is an intentionally strong functional-retention control: this fixed
program can be executed before the late record query is known. Charge its local
execution and do not omit it to manufacture a learned-method advantage.
