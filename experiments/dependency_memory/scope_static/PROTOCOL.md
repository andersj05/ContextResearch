# Separate offline source-analysis control

October 1, 2026. Inspected, constructed development evidence; zero model calls.
This specification does not reopen the completed eight-call scope study,
register natural tasks, or authorize an altered historical experiment. Selection
and implementation are post-hoc development, not a prospective preregistration.

The question is whether a stronger inexpensive AST control removes the apparent
need for model inference in the inspected dispatch program, and where that
control becomes conservative on other program structures. Public source, entry
name and formal parameter names are the only analyzer inputs. It never receives
records, known contracts, finite-catalog labels, historical outcomes or model
responses. It parses ASTs and never executes supplied source. The evaluator
executes only selected trusted repository functions in explicit namespaces.

Three inspected repository programs are dispatch classification, the historical
token-arithmetic validator and normalized-quota validation. They share this
repository and are not independent natural tasks. A fourth, explicitly
constructed family performs lookup with a key revealed at final decoding.
Historical arithmetic constants are program inputs, not current pricing claims.
The quota inputs are constructed; no live account is queried.

Analyze aliases, nested constant keys, membership, type/truth uses and helper
calls. Finite literal helper-key contexts may be joined conservatively. A
dynamic key retains its whole base; unsupported iteration, mutation, recursion
and reflection cause whole-input retention. Unsupported cases remain in the
denominator. This implementation is an access-use heuristic, not a universally
sound Python slicer or a minimal-scope certificate. In particular, complete
finite-catalog agreement is not universal semantic proof.

Reuse the unchanged three-array projection DSL. Use the same existing
`evidence.encode_fields/decode_fields` codec algorithm with a public schema
derived solely from each contract, for every projected arm. Literal dictionaries
and arbitrary values at retained leaves remain literal; this is not a learned
value codebook. Report public schema bytes separately from instance memory.
Keep 4096/1536 UTF-8 byte caps. No clipping or resurrection is allowed.

Check the unchanged dispatch catalog and eight inspected historical records,
a Cartesian token/type/presence catalog, a Cartesian quota/type/window catalog,
and all four-bit late-key lookup inputs. Record original/projection disagreement
and a bounded witness list, exact input/output digests and source hashes.
Malformed inputs and original exceptions stay in the comparison. For dispatch
only, enumerate the same six worker pairs and twenty-four exact final record
queries; the child sees only admitted parent memory and the final decoder only
admitted child memory plus exact identity and public program.

Controls include raw records, cached outcomes of the known public dispatch
function, the existing authored dispatch contract and the historical whole-root
AST contract. Their codec is held fixed alongside the new inferred contract.
The constructed late-key control must retain all potentially queried values;
a table of outputs for all possible keys is an equivalent strong control, not
an information-theoretic disadvantage of caching. No model prompt is altered
or compared on the new programs at this milestone.

Report local CPU/elapsed measurements and read/write bytes separately, without
converting them into credits or a production cost advantage. No paid requests,
provider sessions, hidden archives, extra retained reasoning or late source
rereads are available to these offline actors. Publication priority, general
static-analysis novelty, natural-workflow prevalence, scalable arbitrary-code
inference and fully priced lifecycle benefit remain open. Before any new model
comparison, freeze a separate source/request/evaluator/access/seed/price/budget
contract and include this stronger control.
