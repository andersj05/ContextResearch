October 2, 2026. These six files were copied byte for byte from ignored
`build/completion-spectrum/`. They are mathematical discovery artifacts, not
model trials, natural workflows, independent replications or primary proof.
The captured scripts retain their original workspace-relative paths and are
not repository validation commands. Their original working location matters.

- `screen.py` and `screen.json`: 999 float slopes and five other complementary
  families, 4,995 checks. Two unsigned witness distributions leave negative
  dual gaps near t=0.2. A weak witness is not a better decoder or counterexample
  to unsigned optimality.
- `screen_three.py` and `screen_three.json`: the same 4,995 float comparisons
  with three fixed unsigned distributions and interval cuts 4/25 and 1/4.
  No negative gap is found. The grid does not certify points between samples.
- `polynomial_probe.py` and `polynomial_probe.json`: clear exact dual products
  into 48 integer polynomials and transform intervals using factorial
  convolution. All transformed coefficients are nonnegative. This is a saved
  discovery summary, not sufficient proof by a count or digest alone. The final
  generator rebuilds every inequality with a separate Horner/Pascal interval
  transformation and independently checked arithmetic. The exploratory helper
  was captured after its trailing-zero arithmetic check was repaired; no
  provider execution or authenticated experimental log is asserted.

The final proof uses the selected explicit rational witnesses, not float
values, optimizer outputs or a nearest-marginal optimality assumption. A source
digest preserves the auxiliary bytes. Scientific validity comes from the
analytic reduction and regenerated exact comparisons. No new calls or costs.
