# Preserved post-hoc quantizer discovery

These are actual offline search records, not independent model trials.
The five gzip files decompress to the original JSON bytes pinned in
metadata.json. All 384 final maps receive independent literal routed-loss,
occupancy and outward-entropy grading in the certificate.

protocol.json predates the first three-block fixed-response search. Its
conditional four-block extension was followed after the smaller searches
failed. centroid_protocol.json records the subsequent stated extension:
update centroids using the established ECVQ method. Both remain unchanged.
probe.c, centroid.c, base.h and prepare.py retain the native programs and
C69 warm start; binaries and runtime environments are not committed.

analyse.py and pairs.py retain exploratory float displays. They do not
justify numeric claims. weighted_probe.py/json retain the first forty
loss-weighted calculations on the old margin grid. The subsequent exact
all-allocation search is in production bounds.py. Original terminal outputs
were visible in the chat; separate original complete console files were not
saved. C runtime clock values are platform dependent exploratory records.

All non-oracle points lie above the existing C72 fixed-eight/oracle chord.
All inspected low/high rate-two interpolation scores also have certified
lower bounds above C72's fixed-eight limit. These are negative
entropy/distortion comparisons, not implemented arithmetic-code risks,
global quantizer optima or evidence against larger groups.

For grading, redirect an output to the largest original cell's fixed word
only when doing so lowers its source-conditioned group loss. This also
cannot increase entropy by majorization. The resulting entire quantizer
is fixed before X; no free per-instance selector is supplied.

Metadata retains compiler/version/flags, original and compressed SHA-256
hashes, record counts, closed trajectories and upstream source/result hashes.
No original C69/C71/C72/C73 data or provider allocation is modified.
Zero new model calls and prospective natural episodes.
