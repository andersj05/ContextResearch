# Preserved distortion-cover probes

These are actual local exploratory files from October 2, 2026, after
C72 commit d3fb3fb. They are post-hoc mathematical development,
not prespecified or independent model trials.

- eight_probe.py / eight_probe.json: original eight-response alphabet;
  all 75 integer thresholds for g=1/2/3.
- all_probe.py / all_probe.json: subsequent full sixteen-response alphabet;
  all 75 thresholds. Both probes have the same best errors:
  7/24,9/32,2543/9216. Full words preserve all finite response choices.
- metadata.json: exact file digests, upstream records and sequence.

The final builder also compares the existing scalar-control product
(0,1,14,15), using its full-population risk before X. That control wins
at g=1 and ties at g=2. No source instance selects its own public book.
The g=3 code loses to stronger named finite controls; this failure stays
in the record. All 150 original designs and 1,616 choices are independently
recounted from routed losses.

The scripts preserve their original scratch output paths and imports;
they are historical evidence, not supported package entry points. Console
timing was not saved. The supported reproduction command is in the
[package README](../README.md). Zero model calls or prospective episodes.
Large convergence bounds and the formal family limit are separate from
these three physically built group sizes.
