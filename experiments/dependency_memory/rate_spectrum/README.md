# Parent-rate support spectrum

October 1, 2026. Offline mathematical research, not a model experiment.
Public decoder tables are fixed before each four-bit source; the parent is
formed before R/O and replaced by one child bit before J. No source, parent,
archive, provider session or instance-dependent public table survives its
declared boundary. The source and query law are unchanged from C34.

The algebra reduces the unsigned decoder's supporting optimization, for every
0<t<1, to the total mass p on the six balanced decision words. Odd-weight words
are dominated by a parameter-dependent mixture of constant and balanced words.
There is a unique support transition: two constant words at larger t; those
plus six balanced words at smaller t. This is restricted-family optimality.

Eight rational t values additionally give exact all-decoder support certificates.
Each visits all 4,751 symmetry orbits covering all 1,679,616 tables, including
noncomplementary and repeated endpoints. Other tables use the existing explicit
nearest-word marginal, not an assumed optimum. Rational Gibbs witnesses and
strict information slack give asymptotic upper bounds at reported rational
parent rates; the common supporting objective gives lower bounds for every k.
Different blocks can have different decoder tables and arbitrary joint encoding.

The full unrestricted curve between these support points remains unproved.
No finite codebook at these limiting errors, general coding-theorem novelty,
publication priority, natural task or practical memory/cost gain is claimed.
The source-bound report is regenerated using only the Python standard library:

```powershell
python -m experiments.dependency_memory.rate_spectrum.certificate
python -m unittest discover -s experiments/dependency_memory -p test_spectrum.py -v
```

The six-point floating exploration preceded the derivation. Its saved raw
summary and exact original script are in `auxiliary/`; it is mathematical
discovery, not a numerical proof, preregistration or independent trial. Two
smaller-t points were then added to broaden the checked rates. The final proof
requires neither NumPy nor the exploration's per-table floating weights.
Existing C34 and C59–C64 sources, certificates and provider evidence are unchanged.
