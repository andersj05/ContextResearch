# Mathematical discovery records

The unchanged archived `explore.py` ran from ignored
`build/rate-spectrum/explore.py` on October 1, 2026, using the bundled Python
3.12.14 and NumPy 2.3.5. Its relative root calculation assumes that original
location. The raw `exploration.json` records six deterministic, bounded
4,000-iteration floating probes on the existing 4,751 decoder orbits. The final
per-table floating arrays stay in ignored local build storage; they are not
inputs to the certificate. `default-analysis.json` records the follow-up check
that the existing nearest-word marginal suffices for every nonunsigned orbit at
those points. No model, provider, account or natural workflow was queried.

These are post-hoc mathematical discovery records. Float convergence, timing and
rank comparisons are not proof. The separate rational generator rechecks all
orbits and uses no numerical optimizer, exploration output or NumPy dependency.
The two smaller-t support points were added after the six-point exploration.
