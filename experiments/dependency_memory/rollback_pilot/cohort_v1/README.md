# Authored subscription engineering pilot

This versioned package adapts the sealed E0 episode state machine to the audited
subscription transport. Read the [source and protocol amendment](CONTRACT.md)
before interpreting its results. Its twelve original coding tasks do not stand
in for LiveCodeBench results. The twelve math tasks retain their exact E0 hashes.

`authored.py` creates public tasks, reserved tests, independent finite oracles and
reference programs. `reference_checks.py` executes every retained reference test
in the digest-pinned Docker runtime. `checks.py` saves the access, control-flow
and subscription-accounting tests without model calls.

`run.py freeze` binds the complete cohort, reference checks, E1 evidence, runtime,
source files and all 312 possible call identities before launch. `run.py launch`
creates an exclusive start marker, performs no format or transport retries and
retains all 24 tasks. `run.py verify` checks sources, archive hashes, append-only
accounting, canonical requests, independent math grades, selected-task coverage,
slot dispositions and recomputed analysis. Add `--regrade` to execute public and
reserved coding tests again in Docker; this does not send model requests.

The [organized finding](../../../../research/ROLLBACK_SUBSCRIPTION_2026-10-08.md)
links preparation, live outcomes and verification records. Provider-default
output, unavailable immutable model revision and a small constructed task
distribution limit the conclusions. Later E3/E4/E5 stages are separate plans.
