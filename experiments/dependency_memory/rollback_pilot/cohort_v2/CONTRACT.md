# Corrected Python-language engineering retest, version 2

October 8, 2026. Version 1 omitted Python 3.11 from its original coding actor
statements although the evaluator only runs Python. Several model-selected C++
programs were therefore classified as Python syntax errors. Preserve version 1
and every generation/disposition; do not reinterpret those as a clean model
ability comparison or modify its frozen tasks, sources or evidence.

This version adds a complete Python 3.11 / standard-library / stdin/stdout
requirement to **all twelve coding statements**, before any version-2 request.
The twelve math tasks, coding problem contents, reference programs, retained
tests, task IDs, ordering and four-condition episode logic are identical to
version 1. Every task is retested, including earlier successes; none is selected
or replaced according to its earlier result. This is a post-observation
engineering correction on the same 24 tasks, not a new independent cohort,
held-out confirmation or a LiveCodeBench experiment.

The [version-1 contract](../cohort_v1/CONTRACT.md) supplies the unchanged access,
retry, resource units, grading, conditional admission, output-envelope and
interpretation rules. The new launch has its own exclusive marker, ledger and
at-most-312-call allocation, no cost/token budget ceiling and no credit purchase
or fallback. Version-1 responses, provider threads, checkpoints, reasoning and
private outcomes never enter version-2 actor contexts. Reference checks run again
against the rebound actor hashes before freezing. Both versions' actual call
counts and usage are reported; the observations are not added as independent
tasks. No later-stage or manuscript claim follows automatically.
