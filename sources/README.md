# Sources and evidence

Use [the focused reading guide](READING_GUIDE.md) for the current paper. The larger inherited catalog remains at [catalog/sources.csv](../catalog/sources.csv), with paper and implementation note indexes linked from the main README.

The focused bibliography is [paper/references.bib](../paper/references.bib). Entries imported from reviewed notes retain their known metadata; incomplete bibliographic details are explicitly marked for verification before submission. A source's inclusion is not a claim that every statement in it is correct.

## Pinned implementation evidence

The [September 16 harness snapshots](harness-snapshots/2026-09-16/README.md) contain selected files from public repositories. They support dated implementation observations. They are not complete installations, forks intended for execution, or a record of today's upstream behavior.

The original repository licenses and notices govern third-party source. Source IDs, repository URLs, and pinned commits identify the owners and exact versions. Academic PDFs retain author/publisher rights and access notes in the inherited catalog. This repository does not assign a new license to those materials or to the supplied compaction release.

## Evidence labels

- **Published result:** attribute the exact assumptions and source.
- **Preprint:** distinguish from verified archival publication.
- **Official documentation / pinned code:** date behavior and name the product/API.
- **Local derivation / finite certificate:** provide the proof or reproducible command.
- **Practitioner report:** record attribution and its observational limitations.
- **Hypothesis / planned experiment:** avoid wording that implies a completed result.

The user-supplied Theo/Jev discussion is preserved as a protocol motivation in [the experiment protocol](../docs/EXPERIMENT_PROTOCOL.md). The original post and specific Jev implementation have not been independently audited and should not be used as quantitative evidence.
