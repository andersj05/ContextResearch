# Prospective data-first follow-up after the Luna pilot

September 22, 2026. The completed main pilot has 117 calls and 1.1282525 planning
credits. Inspection of its answers reveals a potential prompt defect: summaries
repeat public gate rules, leaving little space for state. All four structured
child proposals exceeded 440 bytes. One clipped blocker was followed by an unsafe
release. The main schedule and its evidence remain unchanged.

Freeze a **24-call development follow-up** before its answers: one parent, one
child, and four final decisions on each of the same four histories. Keep model
`gpt-6-luna`, medium effort, source histories, caps, timing, final prompts, and
grader fixed. Change only the memory-writing guidance: explicitly announce that
rules and response schema are repeated at later stages, request service data
first, keep complete identifiers, and restrict the child to selected candidates.
This is a prompt package, not an isolated causal test of any one sentence.
No checker, canonical repair, archive, or extra field information is introduced.

Use the remainder of the already announced allocation: **141 total calls after
completion, within the 144-call and 20-planning-credit ceilings**. Seed the shared
adapter's request counter and committed credits from the completed main run;
do not reset the ceiling. Reuse its pinned binary/profile/global instructions and
four-case loopback audit. Every call still gets a fresh isolated process. No
automatic retry and no extra smoke call. A failed or ambiguous dispatch stops.

Score all 16 terminal continuations only after the fixed tranche completes.
Report clipping, identifier fidelity, exact terminal outcomes and all 24 call
costs. Compare descriptively to the original structured, repair, direct, indexed
and full-history arms. The data were used to design this follow-up: it is **not
held-out**, an independent replication, or evidence of statistical significance.
Regardless of direction, retain the result. A strong cheap prompt can defeat the
case for a checker; no positive repair result or novelty claim is assumed.
