The next turn can look right while a later fact is already gone.

        
Immediate continuation only needs the current salt. A unique identifier from wave 1 is not in the compact note. If the user asks for it 200 turns later, this algorithm cannot supply it.

      

      

        Read the reconstructed pseudocode
        
codex_compact(history) -> compaction_summary

    pattern = describe repeating user-block / assistant-template cycle
    latest  = last user payload (prefer exact) + last assistant template
    next    = likely next assistant utterance, as state
    caution = do not invent tools, validation, or derivations

    if history still fits a near-replay:
        emit numbered transcript of blocks + replies
    else:
        emit pattern + latest + next + caution
        drop unique older identifiers

    encrypt as compaction_summary

        
Full write-up: CODEX_COMPACTION_TECHNICAL.md. The five-step obligation-aware walkthrough is a different, proposed compiler: compaction_algorithm_visualizer.html.
