# Focused evidence gap matrix: self-improving harnesses

| Claim family | Evidence required | Existing corpus | Primary gap | Status / next query |
|---|---|---|---|---|
| What is being improved? | Explicit candidate representation and scope | Full-harness, workflow, graph, prompt, tool, memory, role, model-routing, and code-editing sources | Literature uses the same label for very different editable objects | **Covered:** 67 focused papers plus 14 pinned optimizer implementations; preserve the six-axis taxonomy |
| Optimizer mechanism | Search/RL/evolution/program-synthesis details and ablations | ADAS, AFlow, AutoFlow, AgentSquare, GPTSwarm, GEPA, TextGrad, ScoreFlow, SwarmAgentic, EVOTOOL | Optimizer names often exceed what released code implements | **Covered with code checks:** simple random/equal-budget baselines remain an experimental requirement |
| Context compiler as search object | Controlled optimization of retrieval, summaries, tools, memory, and token layout | ACE, Evo-Harness, prompt-compression rate-distortion, QUITO-X, information bottleneck | No paper jointly establishes an operational distortion frontier and valid recursive promotion | **Central thesis gap:** build a bounded self-improving context compiler |
| Genuine improvement | Locked outer tasks, repeated trials, uncertainty, and cost-matched controls | HarnessOpt, Self-Harness, HarnessBank, AFlow, SICA, DGM | “Held-out” data are often reused for promotion; complete search cost is often absent | **Counterevidence acquired:** resolve experimentally with search/gate/test/future splits |
| Cross-model/task transfer | Train/eval matrix across models, domains, and budgets | Meta-Harness, HarnessDev, MemoHarness, Evo-Harness, Harness Updating | Positive and negative cells coexist; executor capability often dominates evolver choice | **Covered enough to reject universal transfer;** crossed factorial estimates remain open |
| Online/continual evolution | Time-indexed deployment data, drift, rollback, delayed outcomes | MemoHarness, ACE, Evo-Harness, Adaptive Auto-Harness | Natural task drift and delayed outcomes are weakly represented | **Partially covered:** future-cohort evaluation remains a research contribution |
| Self-generated tools/skills/code | Executable artifacts, containment, tests, provenance | LATM, CRAFT, ToolMaker, AgentOptimizer, EVOTOOL, Mem2Evolve, SICA, DGM | Reusable capability is rarely separated from benchmark-specific code or macros | **Covered mechanistically;** sealed cross-task reuse is still open |
| Evaluator overfitting | Reusable holdout, adaptive-data-analysis bounds, adversarial audits | Cawley--Talbot, Optimizer's Curse, Russo--Zou, Reusable Holdout, Ladder, Hardt--Ullman, overtuning | Stochastic stateful traces violate several convenient i.i.d. assumptions | **Theory covered:** deriving and testing an agent-specific gate is a central contribution |
| Improvement monotonicity | Acceptance theorem or empirical regression distribution | confidence sequences, SPIBB, reachable-capacity theorem, Self-Harness, Evo-Harness | Existing guarantees are conditional on fixed loss, distribution, class, and immutable gate | **Boundary established:** unconditional monotonicity is unsupported |
| Recursive safety | Authority boundary, signed updates, rollback, invariants, threat model | Gödel Machine, Gödel Agent, STOP, DGM, Everitt, SKETCH, SyGuS, Quine | Unrestricted semantic correctness and safety are not mechanically decidable | **Theory covered:** restrict edits to a typed grammar and keep the root of trust external |
| Cost and sample efficiency | Full outer-loop tokens, calls, trials, human labels, latency | Partial ledgers in AFlow, GPTSwarm, GEPA, SICA, DGM, AgentEvo, Archon | Search cost is still frequently omitted from deployment comparisons | **Open empirical field:** require total and amortized cost frontiers |
| Independent replication | Separate teams, environments, and locked tasks | AFlow's ADAS rerun plus several negative/simple-baseline papers | Most explicitly named 2026 harness work remains unreplicated preprint evidence | **Open by design:** label provisional and prioritize null or sealed-test replications |
